## The goal

The same static addressing skill as in the first lab, but a different network. Two computers on the same `10.0.0.0/24` local network need to see each other directly over L2 — no router involved. You'll manually assign static addresses and verify connectivity with ping.

## IP plan

| Node | Address | Gateway |
|-|-|-|
| PC1 | `10.0.0.11/24` | not needed |
| PC2 | `10.0.0.12/24` | not needed |

## Steps

1. Open the PC1 console and set the address: `ip 10.0.0.11/24`
2. Open the PC2 console and set the address: `ip 10.0.0.12/24`
3. From PC1, verify connectivity: `ping 10.0.0.12`

## Completion criteria

- PC1 has the address `10.0.0.11/24`.
- PC2 has the address `10.0.0.12/24`.
- A ping from PC1 to `10.0.0.12` succeeds.
